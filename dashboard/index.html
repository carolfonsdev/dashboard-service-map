📌 GloboAds Service Map
Visão centralizada das aplicações do ecossistema GloboAds — linguagem, volume de código, endpoints, testes e integrações.

Os dados são gerados automaticamente pelo instalar_servico.py e o mapa exibe sempre a última verificação disponível, mesmo sem o watcher ativo.

Para iniciar ou atualizar o mapa, execute o instalador e informe a pasta que contém os repositórios.
